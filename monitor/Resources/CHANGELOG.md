# Changelog

Release notes for the iOS app, newest first.

The format is the file's contract and what the change log screen parses: each
release is a `## <version>` heading followed by `- ` bullets describing its
changes. Prose outside a heading, such as this paragraph, is ignored.

## 1.0

- Show lightning activity in realtime, history, and animated playback on a MapKit map.
- Fetch from the JSON-RPC and Blitzortung.org HTTP data sources, with region and grid selection.
- Display the own location from a manually set position or the device, with permission-aware modes.
- Warn with proximity alerts through notifications, sound, and vibration, and keep checking in the background.
- Configure the map, animation, data source, location, alarm, and generic behaviour, and export, import, or reset the settings.
- Reach the settings, alarms, application log, change log, and information from an application menu.
